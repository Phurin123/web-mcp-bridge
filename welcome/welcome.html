Welcome to Web MCP Bridge

Connect ChatGPT, Claude, Gemini, DeepSeek, and more to your local MCP tools. Follow these steps; the wizard updates automatically as you go.

  1. 1

    Start or install the launcher

    Browsers cannot launch local programs directly. You can start the bridge manually with Web-MCP-Bridge.cmd, or install the background launcher once via server/install.cmd.

    1. Open the extension folder and run Web-MCP-Bridge.cmd (or server/install.cmd for background auto-start).

    Prefer terminal? python server/install_service.py

  2. 2

    Start the bridge

    The bridge publishes your local MCP servers. You can control it here or from the extension popup.

  3. 3

    Your MCP servers

    Discovered automatically from server/servers.json. Enable them (max 5) and choose permissions from the extension icon.

    • 4

      Try it in your favorite chat

      Open one of these sites with the extension enabled and ask something that uses your tools.
